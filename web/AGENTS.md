# Agents: Pacenote website

- Read `README.md` (build, data, placeholders) and `DESIGN.md` (concept and art direction) first.
- All copy lives in `src/data/site.ts`. No em or en dashes in visible text, sentence case, no
  invented reviews, awards or player numbers. Stats only from `src/data/stats.json`, and label
  them "Sample data" while `sample` is true (the components already do).
- `src/data/stages.json` is generated by the game (`examples/stage_dump.rs`); never hand-edit it.
- Motion runs on one clock (GSAP ticker); page code goes through `onPage()` and returns cleanups.
  Respect reduced motion (no pin, no scrub, the range input drives the stage instead).
- Check with `pnpm build && pnpm check`, then look at the built site at desktop and 390 px.
- Dev server in the background: `pnpm astro dev --background` (port 4410); stop with `astro dev stop`.
